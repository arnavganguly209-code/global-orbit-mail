## Checklist (tasks 1–17)

### 1. SPF
- **Generator (Orbit Admin):** `v=spf1 mx a:{MAIL_HOSTNAME} ip4:{MAIL_SERVER_IPV4} -all`
- **Live `zenspanp.com`:** `v=spf1 mx a:mail.globalorbitmail.cloud -all` → functionally OK; publish upgraded record with `ip4:200.97.170.235` for Workspace-class explicit authorization.

### 2. DKIM
- Orbit generates RSA keys + DNS blueprints (`lib/dns/dkim.ts`, selector `orbit`).
- VPS agent installs PEM into OpenDKIM (`mail-agent.sh` → `dkim.sync`).
- **Public DNS still missing** for customer domains → outbound is unsigned → Gmail/Outlook/Yahoo treat as untrusted.
- **Action:** Publish `orbit._domainkey.<domain>` TXT from Orbit Admin DNS wizard, then run on VPS:
  ```bash
  bash deploy/vps/ensure-opendkim-domain.sh zenspanp.com orbit
  # or rely on Orbit Admin domain create → dkim.sync after OpenDKIM package installed
  ```

### 3. DMARC
- Orbit blueprint now:  
  `v=DMARC1; p=quarantine; rua=mailto:dmarc@DOMAIN; ruf=mailto:dmarc@DOMAIN; fo=1; adkim=r; aspf=r`
- **Publish `_dmarc.zenspanp.com`** (start with `p=none` for 1–2 weeks if volume is new, then `quarantine`).

### 4. PTR / FCrDNS
- **PASS today:** PTR `mail.theglobalorbit.com` → A `200.97.170.235`.
- Desired brand PTR `mail.globalorbitmail.cloud` requires **Hostinger reverse DNS change**. Until then, Postfix EHLO correctly uses `mail.theglobalorbit.com`.

### 5. SMTP EHLO
- Harden scripts set `myhostname` + `smtp_helo_name` from live PTR.
- Roundcube `smtp_helo_host` aligned to same PTR (`ORBIT_SMTP_HELO` / `deliverability.inc.php`).

### 6. Opportunistic TLS
- `harden-deliverability.sh` sets:
  - `smtp_tls_security_level = may`
  - `smtpd_tls_security_level = may`
  - CA bundle + session cache

### 7. Message-ID / Date / MIME-Version / Content-Type
- Generated by Roundcube on every send.
- Postfix: `always_add_missing_headers = yes` (safety net).

### 8. Return-Path
- Envelope sender = authenticated mailbox (Roundcube SMTP AUTH as the mailbox).
- Postfix preserves MAIL FROM → Return-Path on delivery.
- Do not rewrite to a shared null sender.

### 9. SpamAssassin score
- Host may use Rspamd or none. Outbound score is validated via **Mail-Tester**, not only local SA.
- Script reports whether SA/Rspamd is present.

### 10. Mail-Tester ≥ 9.5/10
- Procedure after VPS harden + DNS:
  1. Open https://www.mail-tester.com/ → copy address  
  2. Send from Roundcube (HTML + small attachment)  
  3. Refresh score; fix any red items (usually DKIM/DMARC/SPF/HELO)  
  4. Target **≥ 9.5**

### 11. Gmail “Show original”
Expect:
```
SPF:  PASS with IP 200.97.170.235
DKIM: 'PASS' with domain yourdomain.com (s=orbit)
DMARC: 'PASS'
```

### 12. Postfix review (hurts deliverability if wrong)
| Setting | Desired |
|---------|---------|
| `inet_protocols` | `ipv4` (no IPv6AuthError) |
| `smtp_helo_name` | = PTR hostname |
| `smtp_tls_security_level` | `may` |
| Open relay | locked (`permit_sasl_authenticated` / `reject_unauth_destination`) |
| Missing DKIM milter | hurts more than almost anything else |

Applied by: `deploy/vps/harden-deliverability.sh`

### 13. Dovecot review
- Auth via MariaDB SHA512-CRYPT — do **not** change for deliverability.
- SSL for IMAP/POP is inbound UX, not Gmail outbound placement.
- Script only **reads** doveconf (no auth rewrite).

### 14. Blacklists
External check (2026-07-27): Spamhaus / SpamCop / Barracuda / SORBS — **clear**.  
Re-check anytime: `node scripts/check-deliverability-dns.mjs zenspanp.com`

### 15. Open relay
- Harden sets relay restrictions to authenticated + mynetworks only.
- Local probe expects 55x reject for unauth RCPT to external.

### 16. Gmail / Outlook / Yahoo
| Provider | Config path | Remaining risk |
|----------|-------------|----------------|
| Gmail | IPv4 + SPF + DKIM + DMARC | DKIM/DMARC DNS; new-IP reputation |
| Outlook | Same + TLS | Same; Microsoft filters new senders aggressively |
| Yahoo | Same | Same; DMARC increasingly required |

### 17. Reputation (not configuration)
Even with perfect SPF/DKIM/DMARC/PTR:

- **New / low-volume IPs** land in spam for days–weeks until positive engagement.
- **Shared Hostinger IP history** can carry prior abuse scores.
- **Content** (short links, spammy phrases, large URL ratio) overrides auth.
- **Missing BIMI / Google Postmaster Tools** enrollment slows Workspace-like trust.
- Recommend: Google Postmaster Tools + Microsoft SNDS; warm up with known contacts first.
